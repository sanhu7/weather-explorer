About the app

Weather Explorer shows current weather for any city in the world.

How does it work?

  • Type in a city name
  • The app fetches coordinates via the Open-Meteo Geocoding API
  • Then fetches weather data via the Open-Meteo Forecast API
  • Temperature and wind speed are displayed on the screen

Technologies

  • JavaScript (ES Modules)
  • Open-Meteo API
  • Vitest (unit tests)
  • Cypress (E2E tests)
