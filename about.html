About the app

Weather Explorer is a simple web application that shows real-time weather conditions for any city in the world using open data.Weather Explorer lets you search for current weather in any city in the world. Just type a city name and get instant results!

How does it work?

  • Enter a city name in the search box
  • Click Search to fetch live weather data
  • See temperature and wind speed instantly

Data source

All weather data is fetched from the Open-Meteo API — free and open-source.

Built with

  • HTML, CSS & JavaScript
  • Open-Meteo API (weather data)
  • Geocoding API (city → coordinates)
  • Google Fonts – Nunito
