About the app

Weather Explorer is a simple web application that shows real-time weather conditions for any city in the world using open data.

How does it work?

  • Type in a city name
  • The app fetches coordinates via the Open-Meteo Geocoding API
  • Then fetches weather data via the Open-Meteo Forecast API
  • Temperature and wind speed are displayed instantly

Technologies

  • JavaScript (ES Modules)
  • Open-Meteo API (free & open source)
  • Vitest — unit, DOM & integration tests
  • Cypress — End-to-End tests
